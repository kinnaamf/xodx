# DXWORLD / 2027

Одностраничный статический сайт по присланному дизайну. Файлы для сервера находятся в `dist/`. Node.js на сервере не нужен.

## Что где находится

- `dist/index.html` — разметка, цифры 2027 и кнопки.
- `dist/styles.css` — оформление и мобильная версия.
- `dist/app.js` — музыка, обработка ограничений автозапуска, меню и окно Enter DX.
- `src/emblem.js` — исходник настоящей 3D-модели: неоднородная толщина, выпуклости и впадины в геометрии, сужение кончиков к острию, плавные края, тёмный металл, контурные блики, тень, камера и вращение.
- `src/blade-geometry.js` — две плавные поверхности сходятся в острую кромку по всему внешнему контуру и вокруг всех отверстий. Плоских боковых стенок нет. Направление отражений рассчитывается по производным плавной поверхности, независимо от её треугольников.
- `dist/emblem.js` — уже собранный вариант 3D-кода для браузера.
- `dist/assets/logo-shape.js` — контуры именно присланного знака, включая отверстия.
- `dist/assets/logo-relief.png` — вспомогательная карта силуэта; рабочий рельеф строится геометрией без этой текстуры.
- `dist/assets/site-track.mp3` — единственный трек сайта, без перекодирования.
- `source/dx-logo-source.png` — исходная картинка знака.
- `tools/trace-logo.py` — построение сглаженных контуров из чёрного силуэта на белом фоне с сохранением острых шипов.

## Пересобрать 3D-код после изменений

```bash
npm install
npm run build:emblem
```

Чтобы построить контуры заново после замены исходной картинки:

```bash
python -m pip install pillow numpy
npm run trace:logo
npm run build:emblem
```

## Локальный просмотр

```bash
python -m http.server 4175 --directory dist
```

Открыть `http://localhost:4175/`. Браузер может требовать первое касание для включения звука. Ручная пауза сохраняется до перезагрузки страницы. При отключённом WebGL показывается статичный SVG знака, при включённом системном уменьшении движения вращение останавливается.
